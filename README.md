# navix
======

## Installation

You can install the package via Composer:

```bash
composer require abolaradev/navix
```

You can publish and run the migrations with:

```bash
php artisan vendor:publish --tag='navix-migrations'
```

Then run the migrations:

```bash
php artisan migrate
```

You can publish the config file with:

```bash
php artisan vendor:publish --tag='navix-config'
```

Optionally, you can publish the views using:

```bash
php artisan vendor:publish --tag='navix-views'
```

Optionally, you can publish the assets using:

```bash
php artisan vendor:publish --tag='navix-assets'
```
